
# Projeto 00 — Analisador de Licitações

## Sobre o projeto

Sistema para coletar, organizar e analisar dados de contratações públicas brasileiras, utilizando inicialmente a API do Portal Nacional de Contratações Públicas (PNCP).

## Objetivos

- Desenvolver uma aplicação real utilizando Java.
- Analisar oportunidades e contratações de software.
- Identificar requisitos recorrentes para orientar um futuro ERP.
- Construir um projeto de portfólio profissional.
- Documentar a evolução no Programador Primitivo.

## Tecnologias previstas

- Java + Spring Boot
- PostgreSQL
- Docker
- Git e GitHub

## Escopo inicial (MVP)

1. Consultar dados oficiais do PNCP.
2. Filtrar contratações por período e palavras-chave.
3. Identificar contratações relacionadas a software.
4. Armazenar registros sem duplicações.
5. Gerar um relatório de análise.
